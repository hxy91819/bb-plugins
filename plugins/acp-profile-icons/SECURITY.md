# Security

Report security issues through [GitHub private vulnerability reporting](https://github.com/hxy91819/bb-plugin-acp-profile-icons/security/advisories/new). Include the BB version and reproduction steps; omit credentials and private prompts.

The plugin bundles static icons and runs a frontend renderer plus scoped CSS. It needs no tokens or network requests. BB plugins run with the host's plugin permissions, so inspect a source before installing it.
